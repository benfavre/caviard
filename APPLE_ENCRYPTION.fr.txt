Fonction du produit
Application de caviardage local : lecture, recherche, masquage et export de PDF.
Les documents sont traités sur le Mac. Le compte et les crédits sont gérés par
un service HTTPS ; les packs Mac sont achetés via StoreKit. L'application n'est
pas un VPN ni un service de messagerie et ne propose pas de chiffrement des PDF
exportés. Le caviardage n'est pas lui-même un algorithme de chiffrement.

Fonctions cryptographiques constatées dans le code
- PDF.js 6.3.289 : ouvre des PDF protégés avec le mot de passe fourni par
  l'utilisateur. Le worker embarque ARCFourCipher, AES128Cipher et AES256Cipher.
  Il s'agit d'implémentations embarquées, pas seulement des API Apple.
  Références : src/main.jsx, loadingTask/onPassword ; src/PasswordDialog.jsx ;
  node_modules/pdfjs-dist/legacy/build/pdf.worker.mjs.
- Electron 44.4.5 : inclut Chromium et Node, utilisés pour les communications
  HTTPS avec le compte et le téléchargement des modèles. Le relevé macOS
  du runtime exact est joint dans docs/apple-encryption/ (exécution 41089292464).
- Le code applicatif utilise aussi SHA-256 pour l'intégrité et randomUUID pour
  les identifiants ; ces usages ne sont pas assimilés à du chiffrement de PDF.
- Les clés privées Apple de signature, d'envoi et de vérification des achats
  restent dans les systèmes de compilation ou sur le serveur. Elles ne sont
  jamais intégrées au paquet ni à ce dossier.
